# Q00/ouroboros follow-up usability and verification audit

## Finding

The documented default full-suite command omitted the isolated MCP 2 dependency group. A fresh environment using the general development workflow can fail during collection because MCP 2 tests import the optional mcp package, while the repository keeps MCP 2 in the mcp-test group to avoid the MCP 1.x Claude SDK profile conflict.

The correction is documented in docs/contributing/testing-guide.md:

    uv run --group mcp-test pytest

This is a medium usability and verification-reliability finding. It affects contributor feedback and test-gate discoverability. No production security or architecture contract violation was confirmed in this follow-up.

## Evidence and independent review

The repository dependency declarations and the updated testing guide support the dependency mismatch and the correction. The independent re-review judged the finding partially supported.

The claimed raw-run details, including 38,858 collected tests, seven import errors, and failure at 54 percent of the parallel run, have no preserved raw log or quota measurement in the worktree. Those figures remain unverified. The corrected full-suite command did not complete in the recorded environment because parallel workers exhausted temporary filesystem capacity. A serial full-suite pass remains unverified.

The security suite passed with 335 tests. Ruff format and lint and mypy passed. External vendor runtimes, live network MCP behavior, platform-specific process controls, package-index and self-update behavior, and provider-side telemetry retention remain unverified.

## Changed files

- This report records the reproduction claim, evidence boundary, and residual unknowns.

Revert the documentation commit that adds this report and the testing-guide correction. No production source or runtime behavior is changed by this follow-up.
