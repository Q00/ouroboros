# Security Policy

`dsh-ouroboros` is a config-only bundle that lives inside the main
[Ouroboros](https://github.com/Q00/ouroboros) repository and ships no code of
its own. It follows the Ouroboros security policy.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest (`main`) | Yes |
| older revisions | Best-effort |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Report privately by email to **jqyu.lee@gmail.com**, or through GitHub's
private vulnerability reporting on
[Q00/ouroboros](https://github.com/Q00/ouroboros/security). Include a
description, reproduction steps, and the affected version.

See the full policy, response timelines, and scope in the repository-level
[SECURITY.md](https://github.com/Q00/ouroboros/blob/main/SECURITY.md).
